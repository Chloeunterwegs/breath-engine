# 换气 BreathCatcher · 项目总览（Steering）

> 母题接线：抽象的便利吞掉具体的经验——AI 算得出平均律和声，算不出为等同伴换气而故意慢半拍的支声。
> Kiroween 2026 · Costume Contest 赛道 · Devpost 提交要求详见项目根目录 KIROWEEN-NOTES.md。

## 这是什么
一部「以呼吸为乐器」的生成式音乐 Web 应用。用户对着手机呼吸/哼唱，
AI 合唱（侗族大歌式支声织体）在检测到呼吸周期后「慢半拍」进入——
不是伴奏，是陪你换气。黑暗侗锦质感 UI（Costume Contest 的 haunting 要求）：
恐怖美学承担真实功能——可视化教用户完成呼吸交互，而不是贴纸式恐怖。

## 文化锚点（不可简化）
- 侗族大歌支声（heterophony）：多声部唱腔互相缠绕、故意错开半拍等同伴换气。
  这是「音乐作为社会性等待」的美学，不是装饰性民族风。
- 零侗歌采样：不用任何现成侗歌音频（版权 + 文化尊重）。
  生成引擎用五声调式 + 支声织体算法自建。

## 硬约束
- 纯前端：HTML/CSS/JS + Web Audio API。零后端、零 API Key、零外部 CDN。
- 离线可跑：`python3 -m http.server` 即可演示。
- 移动端可用（3 分钟 Demo 视频要在手机上拍）。
- 全部素材自绘自合成，零版权风险。
