# 换气 BreathCatcher · 项目总览（Steering）

> 母题接线：抽象的便利吞掉具体的经验——AI 算得出平均律和声，算不出为等同伴换气而故意慢半拍的支声。
> Kiroween 2026 · Costume Contest 赛道 · Devpost 提交要求详见项目根目录 KIROWEEN-NOTES.md。

## 这是什么
一部「以呼吸为乐器」的生成式音乐 Web 应用。用户对着手机呼吸/哼唱，
AI 合唱（侗族大歌式支声织体）在检测到呼吸周期后「慢半拍」进入——
不是伴奏，是陪你换气。黑暗侗锦质感 UI（Costume Contest 的 haunting 要求）：
恐怖美学承担真实功能——可视化教用户完成呼吸交互，而不是贴纸式恐怖。

## 文化锚点（不可简化）
- 侗族大歌支声（heterophony）：多声部唱腔互相缠绕、故意错开半拍等同伴换气。
  这是「音乐作为社会性等待」的美学，不是装饰性民族风。
- 零侗歌采样：不用任何现成侗歌音频（版权 + 文化尊重）。
  生成引擎用五声调式 + 支声织体算法自建。

## 硬约束
- 纯前端：HTML/CSS/JS + Web Audio API。零后端、零 API Key、零外部 CDN。
- 离线可跑：`python3 -m http.server` 即可演示。
- 移动端可用（3 分钟 Demo 视频要在手机上拍）。
- 全部素材自绘自合成，零版权风险。

## 方向决定（Marvin Schwaibold 访谈四点收敛 · 2026-11-10）

Marvin 四点——掀引擎盖+DialKit、视觉母题 Helix/Braid、唯一 Showstopper+去杂音、
可打断的物理手感——收敛成三条改造决定，其余全部砍出 MVP：

1. **一个母题讲完全片（视觉母题 + 唯一 Showstopper）。**
   打开第一秒就是全屏暗色侗锦 + 一次呼吸引导：无介绍页、无登录、无满屏按钮。
   全场只有一件事可看——你的一口气（一缕暖色光）走到断气 0.4 秒，旁边浮出第二、第三缕
   光斑慢半拍托住它，拧成支声织体。这个「断气 → 托住」的动作讲完
   「AI 算得出平均律，算不出等你换气的支声」，不需要任何算法词。

2. **参数外置 + 透视开关，但不做完整调参台。**
   声学参数（五声调式、慢半拍延迟、退场秒数）与视觉参数（纹样密度、光斑数量、明灭曲线）
   全部进 js/config.js，禁止写死。MVP 不实现完整 DialKit 滑块面板；
   「透视底层骨架」开关（关掉表层纹样、看声部状态机）是唯一低成本加分项，T8 有余力再做，
   不进验收线。

3. **一切动效可打断、有物理手感，微光随呼吸振动。**
   声部进入/退场、纹样明灭可被随时打断（停止呼吸即退场），有阻尼回弹，不是死板动画。
   背景微光是全局氛围（Ambient Lighting），不是贴纸式恐怖。

## MVP 验收线（硬约束，逐条核）

- `python3 -m http.server` 启动，手机浏览器打开即呼吸触发合唱，全程无任何网络请求。
- 纯前端 HTML/CSS/JS + Web Audio + Canvas 2D；零后端、零 API Key、零外部 CDN。
- 首次呼吸 → 声部回应 → 连续呼吸 → ≥4 声部慢半拍进入 → 停止 8s → 逐层退场。
- 无麦克风可切 Demo Mode（注入模拟呼吸包络）录完整流程。
